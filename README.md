# Sistema de Gestión de Equipos e Insumos TI

Plataforma web para el control de inventario, trazabilidad de activos tecnológicos y gestión de solicitudes de mantenimiento en entornos corporativos.

## Descripción General

Este proyecto surge como solución a la falta de trazabilidad en la asignación de recursos de hardware y software dentro de las organizaciones. Permite a los administradores de TI gestionar el ciclo de vida de cada activo, asignar herramientas al personal y supervisar el historial de mantenimiento de cada equipo.

## Funcionalidades Principales

- **Gestión de Inventario (CRUD):** Registro, actualización y control de estado de equipos informáticos y licencias.
- **Asignación de Recursos:** Control de préstamos e insumos asociados a usuarios o departamentos.
- **Módulo de Mantenimiento:** Registro de incidencias y seguimiento de tickets de soporte técnico.

## Stack Tecnológico

- **Backend:** Node.js, Express.js
- **Base de Datos:** OracleDB
- **Frontend:** HTML5, CSS3, JavaScript (React.js en fase posterior)
- **Control de Versiones:** Git & GitHub
